MyProductivity - это приложение которое позволит людям фиксировать свои достижения в учёбе и мотивировать себя на будущие свершения.

Команда:
- Казаков Сергей - менеджер и тимлид проекта;
- Савенко Владимер - дизайнер;
- Курьянов Николай - разработчик базы данных;
- Азизов Руслан - frontend разработчик;
- Образцов Александр - android разработчик;
- Тулушев Антон - тестировщик.

Цель проекта: разработка прототипа приложения, которое позволит учащимя людям увидить свой прогресс наглядно, дабы решить проблему отложенной выгоды.

Технологии:
- Frontent: xml
- Backend: Kotlin
- База данных: Kotlin Room (SQLlite)
- Инструменты: GitHub
